# opt13_row8：128 路候选（2026-11-10）

基线 opt12_wait；只改加速器数据通路，固件与 FIO 不变。原 opt12 文件未修改。

- 四行扩为八行，每行16路INT16乘法与48位累加；权重共享。
- X：8个行bank，每bank拆K奇偶，各用两个1024×16宏；地址按行号模8分bank。
- 每八行产生一个结果批次；最后99行中的3行只存有效结果。影子累加器扩为8行，存储计数扩为4位。
- 仅支持生产配置 OUT16、DOUBLE_BUFFER、PIPE_MAC、STREAM_MAC、K=64；不支持旧非流水测试配置。

本地行为模型12层通过304128输出，平均20662.6667周期，名义150MHz折算0.137751ms、7259.47层/s。这不是服务器时序通过结论。

服务器包 output/eda/opt13_row8_upload.zip：厂家宏12层回归、官方库门控综合、5工况STA、Formality；任一失败保留目录。旧四行批次单元测试不适用，本轮明确跳过，专门的中途复位/重启/背压测试仍待补齐。不发放功耗脚本，待最终网表与宏活动路径核对后再测12层能耗。

综合检查W宏合并前后允许128×16宏41或25个，1024×16固定16个；将实际映射数量传给STA。宏模型源结构总计137个（含SoC存储），本地沿用测试台的129提示是旧标签，不作宏数量证据。

完整结果见 local_review.json 与 build/opt13_row8/result.json。不得替换opt12冻结提交版，尚未得到新版面积、功耗或能耗数据。
