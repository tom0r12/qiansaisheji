# Complete-task Winograd INT8 compute prototype

This independent core executes one 99×64 by 64×256 linear layer. It is a compute-block experiment, not a replacement for the frozen SoC candidate or a measured PPA result. The baseline intentionally serializes loading, cache reads, paired compute and output. Its interface is fixed in `contract.json`; an enclosing controller must measure the real shared-bus window and drain transport errors.

One accepted BEGIN invalidates task and slot epochs. The 1,600-word X stream is loaded once, including locally generated padding for the absent row 99. Eight successive groups each accept 512 W words and 24 metadata words, then emit two 396-word output tiles. X and all hardware-generated row factors are reused only within that BEGIN. The final core `done` follows the last uncompressed output ACK; it is not the encoder/header/shared-SRAM final ACK.

All arithmetic is exact for signed INT8 X/W and signed INT16 bias before the declared per-channel ties-even shift and signed INT8 saturation. There are no software factor ports. Two signed 8×8 products calculate row/column factors on actual load handshakes. The 128 frozen raw paired lanes each retain only their product/accumulator/control state; four shared correction/RNE paths combine the appropriate row factor, column factor and bias.

The physical storage is eight 1,024×16 X macros, sixteen 128×16 W macros, two 128×16 R-cache macros, and three 128×16 C/bias/shift-cache macros: 174,080 allocated bits, or 21.25 KiB. W slots use addresses `slot*32 + kpair`; four slots fit the existing macro depth but do not create additional ports. No SRAM reads and writes on the same edge in this baseline. The common behavioral single-port project SRAM model is used for local tests. Foundry models, timing and energy remain untested.

`export_vectors.py` reconstructs complete tasks from frozen array vectors, checks their source manifest, and independently recomputes direct 64-product accumulators and scalar RNE results. The 12 real tasks cover all 256 channels for validation sample 9 of each layer; this sample is generated silence, and this is not an official 600-input evaluation. Ten additional full tasks cover operand/bias extrema, RNE ties and seeded full-range random data. Factor files are testbench cache oracles only and are never driven into the design.

`run_checks.py` performs strict RTL lint, checks elaborated SRAM dimensions and 128 raw lanes, compiles the independent testbench and runs three actual simulator random seeds. Tests check every X/W private write, all 99 row factors and 256 column/metadata cache entries, every output word and every pre-RNE accumulator. Directed scenarios include seven abort/reset phases followed by complete fresh reload, held output, and invalid shift metadata in the first and last groups. All three seeds passed: each ran 22 original full tasks, 11 additional successful recovery/stall tasks, seven interrupted tasks and two expected error completions. Each seed checked 861,696 accumulators, including partial outputs before reset/error. The unique real coverage remains 12 layer tasks and 304,128 output elements, not the repeated total.

The final full regression is `build/winograd_task8/20261111T170054752807Z/result.json`. Strict RTL lint has no warnings; an independent four-state Icarus full-task smoke also passed. No-stall complete core cycles are **21,827 = 5,888 load + 259 factor/cache commit + 2,064 cache read + 7,280 paired compute + 6,336 store**. Every no-stall real and synthetic task has the same cycle count. All stalls are included in the complete BEGIN-to-final-Y-ACK window. Exact evidence hashes and the metadata-only post-validation contract status edit are recorded in `VALIDATION.json`; `VALIDATED_CONTRACT.json` preserves the contract bytes used by the run.

The analytical sequential budget is about 21.8k core cycles, already too slow for a 14,354-cycle full-system budget. The next separate revision will retain 128×23 raw sums (2,944 additional FF bits), eight corresponding row factors (168 bits), and output context until final ACK while the next group computes. It must also prefetch R using the separate R macro port during DOT, and account for metadata transitions. Those costs and overlap are not treated as implemented or free in this baseline.
