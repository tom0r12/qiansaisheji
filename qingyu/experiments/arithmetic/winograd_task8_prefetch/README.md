# Full-task compute with concurrent weight loading

This revision preserves the 32-bit task8 streams and all numeric formats, while giving loading and computation independent state machines. `pair_group` now identifies the **load target**, not the output group. `pair_loaded` reports a fully committed group while keeping that group's index visible for the pulse cycle; the following edge advances the target. Output tile/index and `pair_done_index` independently identify the compute/output sequence. The enclosing engine must use this contract when prefetching.

Three 256-bit buffers each assemble eight accepted W words. A full buffer writes all sixteen independent W SRAM banks on one real edge outside DOT reads. Buffer data/address is immutable until this write; accepting the last source word does not prematurely mark the group committed. The additional data/address storage is 768 + 21 = **789 bits**, plus explicit queue pointers, ready bits, counters and control. SRAM allocation remains eight 1,024×16 and twenty-one 128×16 macros (174,080 bits); output snapshots retain the preceding revision's 3,121 bits. No shared SRAM bypass or widened SystemBus is introduced.

Three buffers are required by the actual schedule: two buffers can only supply two of the three DOT_WAIT write edges, because assembling another burst requires eight input clocks. The original two-buffer attempt reached all first-layer numeric checks but failed the required metadata-overlap check; its source and diagnosis remain in `build/winograd_task8_prefetch_smoke2/failure_analysis.json`. This structural finding motivated the third bounded context. It is not counted as a successful candidate run.

The loader may fill the other pair of W slots while the current group computes. Each slot remains reserved until that tile's final raw-output ACK. A new pair starts only when both destination slots are free. Logical tile IDs prevent reuse of a stale generation. Next-group C/bias/shift writes and current-tile metadata reads arbitrate the same three single-port macros, with reads taking priority. Active metadata stays fixed until its tile drains, so there is no hidden second active metadata array.

All row/column factors are calculated from actual accepted data in hardware. All accepted W values are checked against their later physical macro write, along with exact address, bank and slot generation. Tests compare every direct 64-term accumulator and packed result, all 99 R and 256 C/bias/shift entries, source/output backpressure, full burst queues, seven reset phases, and invalid first/last-group metadata. A metadata fault suppresses new snapshots while preserving a previously offered snapshot through its final ACK; the whole task is invalid. The enclosing controller must still drain its own shared-bus traffic before resetting internal streams.

The complete three-seed local regression passed with 12 frozen real layer tasks and ten synthetic full tasks, plus recovery, stall and error scenarios. Each seed completed 33 successful tasks and checked 857,840 accumulators including legal prefixes before abort/error. The unique real set remains 12 layers of validation sample 9 (generated silence), 304,128 unique output elements; this is not an official 600-input evaluation. A four-state substitute makes SRAM Q unknown on writes to test synchronous read/write boundaries; it is a verification model, not a foundry SRAM model.

Measured no-stall private cycles are **9,931 = 2,152 load/wait + 35 factor/cache commit + 272 metadata read + 7,280 paired compute + 192 final output drain**. These are exclusive occupancy counters: loading also occurs during compute, so their load component is not the total number of accepted input words. There are still 5,888 input words and 6,336 output words. In every fast task 512 real wide private write edges commit W; 3,256 W words and 224 metadata cache writes occur during DOT. The result is a private-core measurement; the official loader, CPU, codec and SystemBus complete window must be measured separately, and area/timing/energy remain unsigned.
