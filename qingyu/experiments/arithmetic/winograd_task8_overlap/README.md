# Full-task compute with output and row-factor overlap

This revision preserves the frozen serial task8 public ports, input format, numeric behavior and 29 single-port SRAM macros. Compile either this `winograd_int8_task8.sv` or the serial implementation; both intentionally have the same module name. It remains an independent private compute experiment, not a claim about official loader throughput, frequency or PPA.

One explicit output snapshot retains 128×23 raw sums, eight 21-bit row factors and nine context/valid bits: **3,121 additional retained bits**. The existing raw lanes then compute the next row group while four shared correction/RNE paths drain the previous group. A stalled snapshot can coexist with one completed next raw group; compute then waits. The snapshot is replaced only when empty or on its last output ACK, and the corresponding row factors and tile identity remain stable throughout backpressure.

The separate R-cache macros read the current group's 8 (tail 3) row factors during that group's initial DOT cycles. The preceding group already copied its factors to the snapshot, so the original active-R registers can be reused without a third factor context. C/bias/shift stays fixed for the entire 16-column tile until its final output ACK. The next tile then reads metadata. W loads and paired W reads remain mutually exclusive on the actual single-port macros; spare W addresses do not create extra ports.

Local tests use the existing behavioral SRAM model, with an independent four-state full-task smoke. The full three-seed regression reuses 12 frozen real layer tasks and ten synthetic complete tasks. It checks the direct 64-term integer accumulator before RNE, every packed result, all private X/W writes and R/C cache commits. It additionally checks 1,584 concurrent R reads, 208 snapshots, actual concurrent output transfers, same-cycle snapshot replacement, and a long stall that fills both available contexts before reset/reload.

The measured no-stall private window is **13,891 cycles = 5,888 load + 259 factor/metadata commit + 272 metadata read + 7,280 paired compute + 192 final tile drain**. Of 6,336 output words, 6,144 transfer while subsequent paired compute is active. Compared with the serial private block's 21,827 cycles, this removes 7,936 cycles (36.36%). The complete shared-bus/codec/CPU/loader window must be measured separately; adding those stages can exceed the target even though the private block is below 14,354 cycles.

The physical allocation remains eight 1,024×16 and twenty-one 128×16 macros: 174,080 SRAM bits. The extra snapshot registers, correction path, metadata/control and counters all contribute to eventual area and power. No foundry SRAM functional simulation, synthesis, 150 MHz timing or power result is asserted here. Reproducible commands and source/vector hashes are recorded by `run_checks.py` and `VALIDATION.json`.
