# 组委会 EDA 服务器接入与本工程准备

本说明依据用户提供的 2026NICT EDA 平台使用手册 V10（2026-10-20）及账号分配邮件。
手册里的示例账号、服务器和目录应替换为本队邮件中的分配信息。
密码不写入工程文件，也无需发送到聊天中。

## 首次登录

1. 在 VNC 客户端填写本队邮件中的服务器域名及端口，使用分配的初始密码登录。
2. 打开远程桌面的 Terminal，运行 `vncpasswd`，交互输入并确认新 VNC 密码。
   此平台只识别前 8 个字符；若询问是否创建 view-only 密码，选择 `n`。
3. 再运行 `yppasswd`，按提示输入旧 Linux 密码、设置并确认新 Linux 密码。
   两项修改分别完成后再按邮件要求回复组委会。不能在尚未修改时声明修改成功。
4. FTP 使用 Linux 用户名和修改后的 Linux 密码；它和 VNC 密码是两套独立凭据。

账号分配邮件给出的工作目录优先于手册的通用示例；可以在终端运行
`whoami`、`pwd`、`echo $HOME` 核对本队用户名及目录。
默认 shell 通常为 csh/tcsh，EDA 环境已经预设，不先覆盖 `.cshrc`。

## 文件上传

按账号邮件使用 FTP 主机和端口。将本地生成的 `qingyu_dc_start.zip`
上传到本队远程 home 下的 `Desktop` 目录。FTP 目录可能显示为相对路径，
以登录后可见的 `Desktop` 为准。此包只包含综合准备需要的源码、约束和说明，
不包含私有工艺库、数据集、模型运行环境及完整 SoC 仿真工程。

在远程终端中进入上传目录，依次执行：

```text
cd "$HOME/Desktop"
unzip qingyu_dc_start.zip
cd qingyu_dc_start
sha256sum -c SHA256SUMS
sh scripts/server_probe.sh
```

若目录已存在，先将新包解压到一个新的工作目录，避免覆盖已有结果。
检查脚本仅列出工具路径、`/eda` 两层目录及本队 home 下的库文件候选路径，
将结果写入包内 `reports`；不会连接外部服务、改密、安装软件或启动综合。
如果管理员提供了明确的共享工艺目录，可以把该目录作为脚本参数再次检查。
未在浅层搜索中找到 SRAM 文件，不代表服务器没有 SRAM 库。

## 工具对应关系与执行前条件

| 命令 | 用途 | 当前确认程度 |
|---|---|---|
| `dc_shell` | Design Compiler，RTL 逻辑综合 | 手册列有命令，待实际启动及许可证核查 |
| `pt_shell` | PrimeTime，静态时序分析；功耗取决于相应功能和许可 | 手册列有命令，待实际核查 |
| `fm_shell` | Formality，综合前后等价检查 | 手册列有命令，待实际核查 |
| `verdi` | 仿真结果与波形调试 | 手册列有命令，待实际核查 |

工具命令能找到只表示路径已配置，不能据此声称许可证、时序或功耗通过。
可以在 VNC 终端启动 `dc_shell`，看到正常 DC 提示符后输入 `exit` 返回。
不要将这种工具退出与远程桌面的 Logout 混淆。

正式执行 `dc_shell -f scripts/synth_dc.tcl` 前还需要：

- 组委会认可的标准单元 `.db` 及工艺角；若只有 `.lib`，需在可用授权工具中转换。
- 指定 16 位、128/1024/4096 深度 SRAM 的模型、`.db`、面积及引脚说明。
- 用真实宏替换 `qingyu_sram16` 的封装，匹配读延迟、写使能、片选极性及端口连接。
- 正式输入/输出延迟、时钟不确定度、输入转换时间、输出负载等平台约束。

环境变量名称详见 `docs/synthesis.md`。csh/tcsh 应使用 `setenv`，
不能直接照抄 bash 的 `export`。库路径列表按 Tcl list 规则填写。
当前综合脚本的顶层是 `qingyu_accel`；另有 `qingyu_fio` 接口及实际 SRAM 宏，
最终需将它们纳入赛题规定的面积和时序范围，并完成整 SoC 的活动与功耗分析。

## 平台操作限制

- 手册明确 FTP 只允许上传，不允许主动从服务器下载文件。
  结果应先在 VNC 中查看；如需导出报告或网表，应向组委会确认允许的交付渠道。
- 暂时离开时关闭或最小化 VNC 客户端窗口，不点击远程桌面的 Logout。
- 画质按手册设置为 Medium 或 Low，不选 High。
- 文件上传限速约 200 KB/s；优先上传此小包，避免上传整套本地环境。

本工程至今没有登录该服务器、修改密码、上传文件、发送回执或取得远程 DC 结果。
本地既有功能验证结果保持原有适用范围。
