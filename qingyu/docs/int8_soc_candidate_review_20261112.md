# INT8 系统总线候选评估（2026-11-12）

## 结论

**目前没有候选证明同时达到 10,450 tasks/s、0.5 mm² 和 6.3 µJ/task。** 固定验证集的完整 E203 回归通过；按 CPU 配置至结果 ACK 的工程窗口、并假设 150 MHz，平均值折算约 14,208 tasks/s。但该窗口把输入源预装排除在外。报告中的理想串行装载加计算均值折算约 9,768 tasks/s，低于目标。官方 loader 起点尚未纳入测量，面积、时序和整机能耗均未实测。

冻结主候选仍是 INT16 的 [opt30_fusedpipe4](../current_candidate.json)。INT8 是另一条通过原平台系统总线的实验路线，尚未取代主候选。

## 完整验证集的真实 E203 结果

以冻结的 256 条验证记录分别生成 12 层任务，共运行 **3,072 个真实 E203 任务**，输出元素总数 77,856,768，回归全部通过。该数据集不是组委会最终的 600 条评测。

| 计量口径 | 平均周期 | 150 MHz 换算 | 说明 |
|---|---:|---:|---|
| CPU 配置写接受至最终输出 marker ACK | 10,557.794 | 14,207.5 tasks/s | 测量结果；源输入预装和此前启动未计入 |
| 理想串行装载 + 上述 CPU 窗口 | 15,356.774 | 9,767.7 tasks/s | 理想化估算，不是真实 loader 运行结果 |

第一行高于 10,450 的折算值不能作为官方完整任务成绩。150 MHz 尚未通过该候选的 STA。完整报告摘要和源码身份哈希见[验证摘要](evidence/20261112_full_validation_int8_soc_summary.json)；原始仿真报告留在本地 `build/`，没有作为生成物上传。

本回归固定使用 `winograd_task8_prefetch`、`int8stream_dual` 与 `rice32_bounded`，共享 SRAM 访问经过原 E203 memory fabric。每任务检查完整输出、源数据、地址边界和总线请求/响应。报告记载 255 个样本新跑，另有 1 个结果从相同哈希的已通过运行继承。

## 72 任务架构对照

以下是六个诊断样本 × 十二层的真实 E203 对照。它们用于比较架构，不代表完整验证集分布；每项同样把初始 source preload 放在窗口之外。

| 候选 | 72 任务平均周期 | 范围 | 结果与取舍 |
|---|---:|---:|---|
| 八行预取核 + 双向传输引擎 + bounded Rice | 10,732.667 | 10,084–11,875 | 全部通过，作为整机基准 |
| 九行核 + 同引擎、codec | 10,541.972 | 9,531–11,674 | 全部通过，平均节省约 190.7 拍；额外计算阵列和私有存储需 PPA 对比 |
| 八行单级 MAC 实验 | 10,732.667 | 10,084–11,875 | 全部通过；声明状态减少 2,687 bit，组合关键路径变长，150 MHz 未验证 |
| 八行 fixed400 Rice codec | 10,736.903 | 10,084–11,868 | 全部通过；相对 bounded 少 309 个声明保留状态 bit，但上游握手时序会改变部分任务周期 |

这些位数是 RTL 声明状态的差值，**不等于综合面积**，也不能推出能耗变化。候选各自的 RTL、契约和回归说明位于对应 `experiments/` 子目录。

## 私有 SRAM 紧凑映射

紧凑 X 映射将逻辑上 352 或 416 个有效词分配到 128×16 宏，不改计算核、共享 SRAM 或官方总线。九行核用 48 个私有 128×16 宏、八行核用 53 个；两个映射均没有私有 1024×16 宏。该映射减少存储容量，但增加宏选择和输出 mux，因此不能按 bit 数声称节省了 mm² 或 µJ。

两种紧凑候选的本地物理接口夹具各通过一个完整任务，实际共享宏接口预装并读回 131,072 个词；使用的 SRAM 模型是外置 Q-poison 功能替身，不是厂家模型。`qic8`、`qic9` 包已上传，服务器在 2026-11-12 对两个包都运行了归档哈希检查及 `--mode validate` 并通过；这只检查包完整性，没有启动宏仿真或 EDA。

服务器已找到预期路径下的 RAMSP128X16、RAMSP1024X16、RAMSP4096X16 Verilog 文件并计算哈希。厂家模型身份清单仍未完成，宏仿真、综合、Formality、STA 和功耗分析均未完成。命令和审核输入见[服务器评估说明](../experiments/integration/int8soc_server/SERVER_README.md)。

## 三项目标的当前状态

| 目标 | 当前证据 | 状态 |
|---|---|---|
| 吞吐 >10,450 tasks/s | 预装输入窗口在假设 150 MHz 时约 14,208；理想串行装载口径约 9,768 | **官方完整口径未证明** |
| 新增面积 ≤0.5 mm² | 尚无指定 SCC40 库与厂家 SRAM 宏的同候选综合面积 | **未测** |
| 整机能耗 ≤6.3 µJ/task | 尚无覆盖 CPU、fabric、加速器和所有 SRAM 的同窗口 SAIF 功耗报告 | **未测** |

完整结论还需要真实 loader 窗口、官方选定任务集、厂家 SRAM 功能模型、全 SoC 等价与 150 MHz STA，以及同一完整窗口的功耗。不得将旧共享 SRAM 直连候选的面积或能耗移用到本路线。
